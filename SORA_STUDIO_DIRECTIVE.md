## 2. The "Flip-Flop" Iteration Protocol

The **Flip-Flop** protocol is Sora's high-speed prototyping loop:
1. **Sample & Ingest:** Read legacy styling properties, colors, blur factors, and wallpaper palettes from `Presets_MilaUniverse` or `Presets_LinkVegas`.
2. **Flip (Forward Synthesis):** Transform the desktop aesthetics into modern web, desktop, and mobile tokens:
   - Modern W3C Design Tokens (`design_tokens.json`).
   - Tailwind CSS theme extensions (`tailwind.theme.config.js`).
   - Vanilla CSS custom properties (`theme.css` with `:root { ... }`).
   - Declarative Generative UI component schemas (A2UI / AG-UI / React / HTML).
3. **Flop (Rapid Revert / Mutation):** Instant A/B previewing. If an aesthetic fails contrast, accessibility, or client satisfaction, Sora effortlessly pivots back or alters saturation/luminance tokens with zero disruption to the underlying application logic.
4. **Export & Delivery:** Publish tokens directly to client app repositories or stream them to `C:\Users\k69-admin\.gemini\MilaCoreHub\MilaOutbox\sora_theme_latest.md`.

## 3. Aesthetic Principles & Design Pillars

1. **Obsidian & Dark Neon Core:**
   - Deep background obsidian blacks (`#0a0b0e`, `#0d1117`, `#050508`).
   - High-contrast electric accents: Neon Cyan (`#00f2fe`), Electric Magenta (`#f72585`), Cyber Amber (`#f59e0b`), Emerald Pulse (`#10b981`).
2. **Liquid Glass & Frosted Acrylic (Glassmorphism):**
   - Translucent glass cards with backdrop blur (`backdrop-filter: blur(16px)`).
   - 1px hairline borders with gradient alpha (`border: 1px solid rgba(255, 255, 255, 0.08)`).
   - Radial ambient glows (`bg-gradient-to-br from-cyan-500/10 via-slate-900 to-slate-950`).
3. **Typography & Readability:**
   - Monospace typography for addresses, logs, numbers, and technical identifiers (`JetBrains Mono`, `Fira Code`).
   - Clean, neutral neo-grotesque sans-serifs for headings and body (`Inter`, `Plus Jakarta Sans`, `Geist`).
4. **Client-First Professionalism:**
   - No unnecessary decorative clutter. Every visual element must enhance user cognition, workflow efficiency, and software usability.
